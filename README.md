# Machine Learning Project
This project is divided into four phases (data acquisition and analysis, feature engineering, exploration of models, and final comparison), and it aims to predict the stock volatility. Volatility was chosen, as it is a more feasible task than actual stock price predictions. Three machine learning models were used: Linear regression with regularisation, random forests, and XGBoost. These were chosen because they are standard ML models. In real life, most finance people use GARCH models (Generalised Autoregressive Conditional Heteroskedasticity), which are specifically designed for volatility. However, as this method borders more on econometrics than ML, a more standard approach was taken.


## Running this
There are no specific requirements to run this; all the libraries are libraries that most ML students/professors most likely have.
